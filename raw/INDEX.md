# Raw 文件暫存區

> 任何尚未編譯成正式知識的原始素材都先放這裡：會議轉錄、客戶郵件、競品研究、Slack 截圖。
> 用 `/read-raw` skill 處理，編譯結果會根據性質寫入：
> - `knowledge/round-tables/`（若觸發新議題）
> - `knowledge/decisions/`（若直接形成決策）
> - `context/risk-register.md`（若發現新風險）
> - `knowledge/explorations/`（若是新構思）

## 已處理標記
處理過的 raw 文件第一行：
```
> 已處理：YYYY-MM-DD | 衍生：[去向 1, 去向 2]
```
