# Explorations 團隊版構思探索

> 與單人工作室端 `knowledge/explorations/` 結構同源，但加入「提案者」與「相關 stakeholder」欄位。
> 探索成熟到一定程度即升級為 spec 進入 Roadmap。

## 結構
每個構思一個資料夾：`{YYYY-MM-DD}_{構思名稱}/`，內含：
- `00_問題與假設.md`（含「提案者」「相關 stakeholder」欄位）
- `01_使用情境.md`
- `02_快速prototype.md`
- `03_驗證實驗.md`
- `04_pivot紀錄.md`
- `05_升級決策.md`
- `99_決策歷程.md`

## 與單人工作室端的差異
- 提案者：可能不是 Facilitator 自己
- 相關 stakeholder：列出哪些角色應該被諮詢
- 升級流程：升級為正式 spec 前必須走一場 round-table
